# 小小打字员 · 儿童打字练习程序

一份给一年级小朋友的键盘打字练习网页程序。屏幕显示什么字母，小朋友就用正确的手指把它按出来，程序自动判断对错、记录成绩、按关卡逐步进阶。

---

## 一、程序文件说明

| 文件 | 作用 |
|---|---|
| `HappyType.html` | 主程序，双击即可在浏览器中打开使用 |
| `config.js` | 关卡与词库配置文件，想改关卡、词库就改它；没有它程序也能正常运行（自动使用内置默认关卡，主页会提示下载一份） |
| `使用说明与设计思路.md`（GitHub 上即本文档 README.md） | 使用说明与配置手册 |

> 三个文件必须放在**同一个文件夹**里。复制给别的电脑时，整个文件夹一起复制。
> 进度（星星、解锁、历史最好成绩）保存在**浏览器本地**，换电脑或换浏览器不会带过去。

---

## 二、使用方法

### 1. 打开程序
双击 `HappyType.html`，用 Chrome / Edge 等浏览器打开即可，**无需联网、无需安装**。

### 2. 训练套餐（默认 16 关）
| 关卡 | 内容 | 练什么 |
|---|---|---|
| 1 指法小课堂 | 讲解 + F/J 定位键练习 | 学会放手指 |
| 2 基本键左手 | ASDFG | 左手基本键 |
| 3 基本键右手 | HJKL; | 右手基本键 |
| 4 基本键训练 | ASDFGHJKL; | 双手基本键 |
| 5 上排键左手 | QWERT | 左手向上伸 |
| 6 上排键右手 | YUIOP | 右手向上伸 |
| 7 上排键混合 | QWERTYUIOP | 上排一起练 |
| 8 上中排混合练习 | 上排 + 中排 | 两排混合 |
| 9 下排键左手 | ZXCVB | 左手向下伸 |
| 10 下排键右手 | NM,./ | 右手向下伸 |
| 11 下排键混合 | ZXCVBNM,./ | 双手向下伸 |
| 12 字母大挑战 | 26 个字母混合 | 全键盘 |
| 13 单词练习 | cat、dog、sun… | 组合输入 |
| 14 短句练习 | i can run. 等 | 空格和标点 |
| 15 计时挑战 | 60 秒限时 | 速度 |
| 16 自由练习 | 26 字母 | 随意练习 |

完成上一关（拿任意星级）即可解锁下一关。**自由练习**永远开放。想让孩子随便玩，可给每关都加 `alwaysOpen: true`。

### 3. 练习过程
- 屏幕中间是一行**打字机字母**：左边是**已经打对的字符**（绿色，打错的字符不显示在这一行上），中间是**当前要打的字母**（最大、带橙色下划线），右边是**接下来 3 个预告字母**（灰色、逐个变小），每打对一个就向右推进一格，像打字机一样从左到右"打"出来，提前知道后面要按什么键
- 单词/短句模式整串词已经完整显示在屏幕上，无需预告
- 屏幕下方提示**用哪只手、哪个手指**（左手小指在最左，右手小指在最右，大拇指管空格）
- 按**对**：字母变绿、键盘键变绿、播放轻快音效、连击 +1
- 按**错**：字母抖动、播放提示音，统计为"打错"
- 每打完一个单词会弹出鼓励语（"真棒！""好厉害！"）
- **盲打模式**：点主页右上角的"眼睛"按钮（全局开关，对每一关练习都生效），隐藏屏幕上的键盘和手指提示，原位置改为显示**你实际输入的字符**（打对的绿色、打错的红色、最新一个带下划线；打错的字符只在这里显示，不会出现在上方的打字机字母行里），练熟后不低头看键盘，也能对照知道自己按了什么

### 4. 成绩与星星
- 每关做完显示：**正确率、每分钟个数、打对、打错**
- 按正确率得星星：≥95% 得 3 星，≥85% 得 2 星，其余得 1 星（完成即鼓励）
- 主页右上角显示**星星总数**，卡片上有本关已获星星

### 5. 常用操作
- 右上角**喇叭图标**：开关音效
- 右上角**眼睛图标**：隐藏键盘开关（全局生效，隐藏键盘和手指提示，改为显示实际输入的字符），选择会记住，下次打开仍生效
- 练习页左上角**返回箭头**：退出练习（进度不保存，重新开始）
- 结果页：**再来一次 / 下一关 / 回到主页**
- 支持**触屏**：点屏幕上的键盘键也可以输入（平板可用）

## 三、配置说明（如何改关卡）

所有关卡都在 `config.js` 里，**改完保存、刷新页面即生效**。主文件不用动。

### 1. 字段速查
```js
{
  name: "基本键训练",             // 卡片上的名字
  kind: "letters",               // 类型：lesson 入门 / letters 单字母 / words 组合 / timer 计时
  chars: "asdfghjkl;",           // 该关练哪些字母（写在一起，不分隔）
  count: 20,                     // 练多少个（组合=几个词，计时=不用填）
  words: ["cat","dog"],          // 组合练习的题目，可省略（省略用全局词库）
  time: 60,                      // 计时挑战的秒数（仅 timer 用）
  desc: "左手 ASDF · 右手 JKL;",  // 卡片说明
  badge: "基本键",                // 卡片角标
  color: "#43AA8B",              // 角标颜色（可选，不写自动随机配色）
  alwaysOpen: true               // 加这一项=不锁定，随时能玩
}
```

> **关卡没有 id 序号**：`levels` 数组的**顺序就是关卡顺序**（第 1 个=第 1 关），中间加关、删关都不需要调整任何序号。

### 2. 常见修改示例
**加一关**：想加在**最后**，在 `levels` 数组最后一个 `}` 前用英文逗号接上：
```js
{ name: "数字键练习", kind: "letters", chars: "1234567890", count: 20, desc: "认识数字键", badge: "数字" }
```
想加在**中间**（比如在第 3 关和第 4 关之间），直接把这段插到对应位置即可，**不需要改任何序号**。

> ⚠️ 中途插入关卡后，**后面关卡的已存星级会顺移到新位置**（如原第 5 关的星星会变成插入后的第 6 关）。想清空旧进度重新玩，可在浏览器按 F12 → 控制台执行 `localStorage.removeItem("typing-kids-progress-v1")` 后刷新。

**改某一关的字母**：把 `chars` 引号里的字母换成想要的，如 `chars:"asdf"`。

**改练习数量**：调 `count` 的数字，如把 20 改成 30。

**把某关改成不锁定**：在该关的 `}` 前加 `, alwaysOpen: true`。

**去掉一关**：删掉对应那一段（含前后逗号调整）。

**改计时秒数**：改计时挑战那关的 `time`，如 `time: 90`。

**固定某关的颜色**：在该关里写 `color: "#FF9F1C"`；不写这行，程序会每次随机配色。

### 3. 词库
- 全局词库在 `words: [...]` 里，单词用英文双引号包住、逗号隔开
- 单词关卡没写自己的 `words`，用的就是全局词库
- 短句关卡把句子直接写在它自己的 `words` 里（句子可以有空格、逗号、句号）

### 4. 配置文件缺失了怎么办
- 程序目录下没有 `config.js` 时，程序**自动使用内置默认关卡**（与 `config.js` 内容一致，共 16 关：指法小课堂 → 基本键左/右 → 上排左/右 → 上排混合 → 上中排混合 → 下排左/右 → 下排混合 → 字母大挑战 → 单词 → 短句 → 计时 → 自由），不影响正常使用
- 主页会出现黄色提示条，点上面的**"下载配置文件"**按钮，浏览器会下载一份默认的 `config.js`，把它放到主程序同目录即可开始自定义

### 5. 修改红线
- 引号一律英文双引号，数字不加引号
- 每条之间英文逗号，最后一条不加逗号
- 别删最外层 `{ }` 和结尾分号
- 改完刷新浏览器，若页面卡在主页没反应，多半是配置文件写错了：检查括号、逗号、引号

## 四、设计思路

### 1. 为什么做成网页单文件
- 零安装、零依赖，双击即用，适合家庭电脑和学校机房
- 单机运行，无隐私与联网问题；进度存浏览器本地
- 关卡数据外置成 `config.js`，家长/老师不用碰代码就能调整内容

### 2. 教学路径：从基本键出发，循序渐进
一年级儿童初学键盘的核心难点是**手指分工**。程序设计严格遵循标准指法路径：
**定位键（F/J 凸点）→ 基本键（ASDF JKL;）→ 上排 → 下排 → 全键盘 → 单词 → 短句 → 计时 → 自由**。
每关只引入一组新键，上一关未过不解锁下一关，保证"练熟再前进"。

### 3. 符合儿童心理的反馈设计
- **即时判定**：按对立刻变绿、按错立刻抖动，强化"对了/错了"的感知，不让孩子猜
- **虚拟键盘高亮 + 手指提示**：屏幕即"教具"——目标键闪烁、左右手分区着色（左蓝右橙）、F/J 带凸点、手指小图标指出用哪个手指，把抽象的指法具象化
- **鼓励为主**：完成即得星、连击计数、随机鼓励语、完成旋律，保护兴趣；错误不惩罚、不扣分，只提示
- **正体字母**：练习内容统一使用标准无衬线正体字母（Segoe UI/Arial），避免花体影响一年级孩子认读
- **盲打模式**：键盘与手指提示是"扶着走"，练熟后可用右上角眼睛按钮隐藏，改为显示实际输入字符（对绿错红）作为盲打反馈，逐步过渡到不看键盘；设置保存在浏览器本地

### 4. 技术实现要点
- 原生 HTML/CSS/JS 单页，无框架无构建；视图用状态机切换（主页/课程/练习/结果）
- 键盘判定监听全局 `keydown`，忽略 Ctrl/Alt 组合键，大小写归一比较
- 音效用 Web Audio API 现场合成（正确音、错误音、完成旋律），零音频文件；首次点击后启用，符合浏览器自动播放策略
- 计时模式用 `setInterval` 倒计时驱动，结束后自动结算
- 成绩用 localStorage 持久化（关卡星级、解锁状态、历史最佳正确率与速度）；关卡以**数组顺序**为身份（不再用 id 序号），旧版进度在打开时会自动迁移，中途插入关卡不影响程序运行
- 关卡卡片颜色可缺省，未配置时从内置色板随机选取
- 响应式适配电脑与平板；支持触屏点按虚拟键盘
